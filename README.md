# YTshorts-Blocker
A userscript that blocks YouTube Shorts. It removes the 'Shorts' option from the left-hand menu and prevents Shorts from appearing in search results or on the homepage.

## Why I made this?
YouTube Shorts have often distracted me while I was looking up important information on YouTube. In fact, I find them to be nothing more than a distraction on the platform itself.

## How can you use it?
First, install the Violentmonkey extension (https://violentmonkey.github.io/) or another userscript loader extension.
Open this webpage: https://raw.githubusercontent.com/zoardgodor/YTshorts-Blocker/main/ytshorts-blocker.user.js

If everything goes as expected, Violentmonkey will offer to install it. After installation, you will also need to configure the extension to allow user scripts.
After this, you will see that the Shorts do not appear on the page.

(The userscript only works on youtube.com.)
